HƯỚNG DẪN CHẠY GAME - BẢN 1 FILE

1. Giải nén file ZIP.
2. Bấm đúp vào file `mario_game_mo_la_chay.html`.
3. Mở bằng Chrome, Edge hoặc Cốc Cốc.
4. Bấm nút “Bắt đầu”.

Bản này đã gộp toàn bộ CSS, câu hỏi và JavaScript vào 1 file HTML nên ít lỗi hơn bản nhiều file.
Nếu vẫn không chạy:
- Hãy giải nén trước, không mở trực tiếp trong cửa sổ xem trước của ZIP.
- Dùng Chrome/Edge/Cốc Cốc.
- Cho phép trình duyệt chạy JavaScript.
